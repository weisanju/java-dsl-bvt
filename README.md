# java-dsl-bvt

基于 Java 的 BVT（接口测试）平台规划仓库。

当前规划采用**极简实现路径**：`Spring Boot + PostgreSQL + QLExpress`，不引入额外中间件，并采用 **TDD 驱动开发**。
